### New namespace details

**w16du** (`http://schemas.microsoft.com/office/word/2023/wordml/word16du`):
- Contains a single attribute: `dateUtc` of type `xsd:dateTime`
- Purpose: Provides UTC timezone-aware timestamps on revision marks (track changes).
  Supplements the existing `w:date` attribute which uses local time.
- Impact: Documents from Word 2023+ include `w16du:dateUtc` on `w:ins`, `w:del`,
  `w:rPrChange`, etc. alongside the traditional `w:date`.
- Added to Open XML SDK in v2.20.0 (Apr 2023).

**w16sfl** (`http://schemas.microsoft.com/office/word/2024/wordml/sdtformatlock`):
- Contains a single attribute: `formattingAllowed` of type `w:ST_OnOff`
- Purpose: Controls whether formatting is allowed within content controls (SDT).
  Extends the existing SDT locking behavior (`w:lock`).
- Impact: Documents from Word 2024+ may include `w16sfl:formattingAllowed` on
  `w:sdtPr` elements.
- First appeared in MS-DOCX v21.2 (Feb 2025).
