# T-0017: Character spacing — implement w:spacing for character-level spacing in Font/RunFormat

**Status**: DONE | **Size**: M
**Phase**: —

## Context
The gap analysis marks character spacing (`w:spacing` in run properties) as not implemented. This controls inter-character spacing (tracking/kerning), character position (raise/lower), and character scale — common formatting in professional documents. The `w:rPr/w:spacing` element uses `@w:val` for spacing in twips, and is distinct from paragraph-level `w:spacing` which is already supported.

## Acceptance Criteria
- [x] `Font.spacing` property reads/writes `w:rPr/w:spacing/@w:val` (character spacing in twips, exposed as Length)
- [x] `Font.kern` property reads/writes `w:rPr/w:kern/@w:val` (kerning threshold in half-points, exposed as Length)
- [x] `Font.position` property reads/writes `w:rPr/w:position/@w:val` (raise/lower in half-points, exposed as Length)
- [x] Properties return `None` when not set (inherit behavior)
- [x] Round-trip fidelity preserved
- [x] All existing Font tests continue to pass

## Approach
Follow existing Font property patterns (e.g. `Font.size`/`CT_RPr.sz_val`):
1. Add `ZeroOrOne` declarations on CT_RPr for `w:spacing`, `w:kern`, `w:position`
2. Add `CT_SignedHpsMeasure` class for `w:position` (signed half-points)
3. Add `ST_SignedHpsMeasure` simple type for signed half-point conversion
4. Add `val` attribute to existing `CT_Spacing` for run-level character spacing
5. Add value properties on CT_RPr: `spacing_val`, `kern_val`, `position_val`
6. Add Font proxy properties: `spacing`, `kern`, `position`
7. Register new element types in `oxml/__init__.py`
8. Add parametrized tests
