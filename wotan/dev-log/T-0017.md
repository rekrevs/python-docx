# T-0017: Character spacing — implement w:spacing for character-level spacing in Font/RunFormat

**Status**: READY | **Size**: M
**Phase**: —

## Context
The gap analysis marks character spacing (`w:spacing` in run properties) as not implemented. This controls inter-character spacing (tracking/kerning), character position (raise/lower), and character scale — common formatting in professional documents. The `w:rPr/w:spacing` element uses `@w:val` for spacing in half-points, and is distinct from paragraph-level `w:spacing` which is already supported.

## Acceptance Criteria
- [ ] `Font.spacing` property reads/writes `w:rPr/w:spacing/@w:val` (character spacing in half-points or Pt)
- [ ] `Font.kern` property reads/writes `w:rPr/w:kern/@w:val` (kerning threshold)
- [ ] `Font.position` property reads/writes `w:rPr/w:position/@w:val` (raise/lower in half-points)
- [ ] Properties return `None` when not set (inherit behavior)
- [ ] Round-trip fidelity preserved
- [ ] All existing Font tests continue to pass
