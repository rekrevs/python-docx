## Context
Microsoft 365 with Copilot has introduced new document creation workflows (agent mode, direct editing, image interpretation). While these use standard OOXML, Copilot-generated documents may favor certain patterns (structured headings, content controls for templating) or include newer namespace extensions. We need to validate that our fork handles modern Office 365 output correctly.

## Acceptance Criteria
- [ ] Obtain sample documents created/edited by current Office 365 (ideally with Copilot features)
- [ ] Run round-trip test: open → save → compare for structural fidelity
- [ ] Verify no unknown namespace warnings or element drops
- [ ] Confirm all extension features (SDT, fields, bookmarks, etc.) work on modern documents
- [ ] Document any new patterns or elements found
